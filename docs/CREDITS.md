## Pictures and the model

- The headphone is built in code from lathe, tube, and torus geometry. There is no downloaded GLB or OBJ.
- Studio lighting is a mix of Three.js lights and drei `Lightformer`s. No HDRI file is shipped.
- The six gallery plates and the noise tile are generated by `scripts/build-assets.mjs`. They are original and can be regenerated.
- The grain overlay is that generated noise tile.

## What this is not

Lyra is not for sale. The specifications in the site are internally consistent fiction, not laboratory measurements. The reserve dialog says so in the interface, not only in this file.
